# 🤖 CloudWays Auto Signup Bot

A Telegram bot for automatic CloudWays account creation.

## Features
- ✅ Single account creation
- ✅ Bulk account creation  
- ✅ Credit system
- ✅ Referral program
- ✅ Account management

## Developer
**@PRIME_X_ARMY**

## Setup
1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set your bot token in `config.py`
4. Run: `python main.py`

## Requirements
- Python 3.8+
- Telegram Bot Token
- Chrome Browser
